# User Guide

## Getting Started

### Login
Navigate to the application URL and log in with your credentials. Your administrator will provide your username, password, and tenant.

### Navigation
- **Tasks** - View and manage your assigned tasks
- **Processes** - Start new processes and view running instances
- **Forms** - Access form builder and saved forms
- **Dashboard** - View analytics and custom dashboards

## Task Management

### My Tasks
View tasks assigned to you. Each task shows:
- Task name and description
- Due date and priority
- Process instance it belongs to

### Actions
- **Claim** - Take ownership of an unassigned task from the pool
- **Complete** - Submit the task with required form data
- **Delegate** - Transfer the task to another user
- **Add CC** - Add users who should be notified of task progress

### Task Expiration
Tasks with due dates show expiration alerts. Overdue tasks are highlighted in red.

## Collaboration

### Comments
- Add comments to any task or process instance
- Use **@username** to mention other users (they receive notifications)
- View the full comment history in the process timeline

### Attachments
- Upload files to tasks using drag-and-drop or the file picker
- Supported formats: PDF, images, Office documents
- Maximum file size: 10MB per file

## Processes

### Starting a Process
1. Navigate to **Processes**
2. Select a process definition
3. Fill in the start form
4. Click **Start Process**

### Viewing Process History
Click on any process instance to see:
- Current status and active tasks
- Timeline of all events, comments, and attachments
- Process variables

## Dashboards

### Pre-built Dashboards
Access default dashboards showing:
- Task completion efficiency
- Process distribution
- Bottleneck analysis
- SLA compliance rates

### Custom Dashboards
1. Navigate to **Dashboard > Custom**
2. Add widgets from the palette (bar, line, pie, funnel charts)
3. Configure data sources and filters
4. Save and share with your team
